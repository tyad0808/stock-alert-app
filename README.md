# 원칙 알림 (stock-alert-app)

5년간 지켜온 투자 원칙을 기준으로 시장을 대신 감시하고, **원칙에 맞는 순간에만 알려주는 앱**입니다.

- 매수·매도 주문 기능은 **없습니다**. 증권사 정보는 조회만 합니다.
- 판단과 주문은 언제나 사장님이 증권사 앱에서 직접 합니다.
- 전체 기획: [docs/기획서.md](docs/기획서.md)

## 지금 상태: 1단계 (연습용 데이터)

| 기능 | 상태 |
| --- | --- |
| 앱 기본 화면 (하단 탭 5개) | ✅ |
| 시총 Top 10 감시, 1년 고점 대비 하락률 | ✅ 연습용 데이터 |
| 매수 검토 알림 (-30%부터 5%p마다) | ✅ |
| 같은 종목·같은 구간 하루 1번, 이상값 "데이터 확인" | ✅ |
| 종목 상세 (1년 가격 그래프, 알림 구간 가격표) | ✅ |
| 키움 실제 시세 연결 | ⏳ 서버(고정 IP) 준비 후 |
| 보유 종목 알림, 3분할 계산기 | ⏳ 2단계 |
| 아침 브리핑 | ⏳ 3단계 |
| ETF Top 10 | ⏳ 4단계 |

## 연습 모드 사용법

키움을 연결하기 전이라 **가짜 가격**으로 움직입니다. 화면 위 주황색 띠에서:

1. **하루 진행**: 다음 거래일로 넘어갑니다. 새 알림이 생기면 아래에 잠깐 표시됩니다.
2. **5일**: 5거래일을 한 번에 넘깁니다.
3. **처음부터**: 알림 기록을 지우고 첫날로 돌아갑니다.

연습 데이터에는 이런 장면이 들어 있습니다 (총 60거래일).

- 메타: -40%에서 시작해 -45%, -50%로 점점 깊어짐
- 엔비디아: -30% → -35% → 회복 → 다시 하락
- 테슬라: -30% 진입, 중간에 **오류 데이터 하루** (알림 대신 "데이터 확인")
- 알파벳·TSMC: -30% 근처를 들락날락
- 마이크로소프트·브로드컴 등: 고점 근처라 알림 없음

## 개발자용 (Claude Code가 읽는 부분)

```bash
pip install -r requirements.txt
python -m pytest              # 자동 테스트
uvicorn app.main:app --reload # http://localhost:8000
python -m app.checker         # 시세 확인 1회 (서버에서 주기적으로 실행)
```

설정은 `.env` 파일로 합니다. 이름은 `.env.example` 참고. `.env`는 GitHub에 올라가지 않습니다.
