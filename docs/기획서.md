## 1. 개요

5년간 지켜온 투자 원칙을 기준으로 시장을 대신 감시하고, **원칙에 맞는 순간에만 알림을 보내는 시스템**이다. 매수·매도 주문은 하지 않는다. 판단과 주문은 언제나 사장님이 직접 한다.

**배경**

- 투자 경력 5년, 시드 약 3,000만 원으로 누적 수익 약 2.1억 원, 손실 마감 없음
- 차트 지표나 용어 없이 원칙과 감으로만 운용: 1년 고점 대비 많이 빠진 빅테크를 3분할(30/30/40)로 매수
- 지금은 사장님이 직접 가격을 확인 → 본업(Broad) 중에는 놓치는 구간이 생김

**시스템이 하는 일**

- 폰에 설치해 쓰는 **앱 형태**: Top 10 시세판, 보유 현황, 공지사항, 알림을 한 곳에서 확인
- 시총 Top 10 **실시간 시세판**: 앱을 열면 종목마다 현재가, 1년 고점, 1년 고점 대비 몇 %인지 바로 보임
- 1년 고점 대비 -5%부터 5%p마다 알림. **매수검토(-5~-15%)**와 **매수권장(-20% 이상)**을 색으로 구분 (ETF Top 10도 같은 기준)
- 보유 종목은 증권사 조회로 가져온 내 평단 기준, 수익률 +5%마다·손실률 -10%마다 알림
- 시총 Top 10 종목의 그날 이슈(실적, 공시, 큰 가격 변동 사유)를 밤사이 알림과 함께 매일 오전 9시 아침 브리핑으로 신문처럼 한 번에 전달
- 모든 알림과 종목 현황을 기록해, 사장님 감을 숫자로 확인 가능

**시스템이 하지 않는 일:** 매수·매도 주문, 종목 추천, 매수·매도 의견. 주문 기능은 코드에 아예 넣지 않고, 공지사항도 "무슨 일이 있었는지" 사실만 담는다.

## 2. 투자 원칙의 규칙화

원칙은 그대로 두고, 시스템은 "언제 사장님에게 알릴지"만 규칙으로 정한다. 숫자는 사장님이 말한 기준을 그대로 옮겼고, 10장에서 최종 확정한다.

| 사장님 원칙 | 시스템 규칙 | 기본값 |
| --- | --- | --- |
| 절대 남 말 듣지 않기 | 알림 판단 근거는 가격과 내 평단뿐. 공지사항은 사실 요약만 보여주고 알림 판단에는 쓰지 않음 (의견·추천·커뮤니티 글 제외) | 입력 = 시세 + 평단 |
| 빅테크만 (잡주·성장주 금지) | 미국 시가총액 상위 10개 종목 + 규모(순자산) 상위 10개 ETF를 감시. 알림 기준은 같고 화면만 분리 | 종목 Top 10 + ETF Top 10 (매월 갱신) |
| 1년 고점 대비 많이 빠졌을 때 매수 | 최근 1년(52주) 최고가 대비 하락률이 구간에 들어오면 알림. 상황에 따라 -15·-20% 구간에서 분할매수를 시작할 수 있으므로 얕은 구간부터 알림 | -5%부터 5%p마다 끝까지. **매수검토** -5·-10·-15%, **매수권장** -20%부터 |
| 3분할 매수 (30/30/40) | 종목별 총 투자금을 입력하면 30/30/40으로 자동 계산해 앱과 알림에 표시. 주문은 하지 않음 | 자동 계산 |
| 매도는 스스로 선택 | 매도 시점을 판단하지 않음. 내 평단 대비 수익률·손실률 구간만 알림 | 수익 +5%마다, 손실 -10%마다 |

시총 Top 10에서 빠진 종목이라도 **보유 중이면 보유 종목 알림은 계속** 보낸다. 감시 목록에서 빠졌다고 알림이 끊기면 평단 관리가 안 되기 때문이다.

## 3. 시스템 구성 및 기능 명세

시스템은 가격과 내 평단만 보고 원칙 구간에 들어온 종목을 골라 아침 브리핑으로 알린다. 그다음 매수·매도는 사장님이 증권사 앱에서 직접 한다.

```text
[설정: 종목·ETF Top 10, 알림 구간]        [Top 10 이슈 수집: 뉴스·공시 사실 요약]
              ↓                                        ↓
[시세·평단 조회: 키움 REST API] → [원칙 엔진: 1년 고점 대비 하락률, 평단 대비 수익률] → [알림 필터: 중복 차단·이상값 표시]
                                                                                              ↓ (밤사이 모아서)
[기록: 보유·평단·알림 이력, 지난 브리핑] ← [사장님 직접 판단: 증권사 앱에서 매수·매도] ← [앱 · 아침 브리핑 (매일 9시)]
```

설정은 사장님만 바꿀 수 있고, 외부 뉴스나 추천은 어떤 모듈에도 들어오지 않는다. 직접 매수·매도한 결과는 평단에 반영되어 다음 알림 기준이 된다.

## 4. 알림 로직 상세

알림은 **Top 10 하락 알림**과 **보유 종목 알림** 두 종류다. 각 구간은 처음 들어갈 때 1번만 알려서, 같은 내용이 반복해서 오지 않게 한다.

**A. Top 10 하락 알림 — 감시 종목이 1년 고점 대비 빠졌을 때**

| 구간 | 단계 | 예: 1년 고점 $200일 때 가격 |
| --- | --- | --- |
| -5% | 매수검토 (주황) | $190 |
| -10% | 매수검토 (주황) | $180 |
| -15% | 매수검토 (주황) | $170 |
| -20% | 매수권장 (빨강) | $160 |
| -25% | 매수권장 (빨강) | $150 |
| -30% 이후 | 매수권장 (빨강), 5%p마다 끝까지 | $140, $130 … |

알림은 바쁠 때 놓치지 않기 위한 보조 수단이다. 평소에는 앱의 시세판에서 모든 종목의 위치를 직접 확인한다.

**B. 보유 종목 알림 — 내 평단 기준**

| 종류 | 간격 | 예: 평단 $100일 때 알림 가격 |
| --- | --- | --- |
| 수익 알림 | +5%마다 | $105, $110, $115, $120 … |
| 손실 알림 | -10%마다 | $90, $80, $70 … |

**알림 예시 (브리핑에 들어가는 형태)**

```text
[매수권장] 종목 A · 1년 고점 대비 -35% 진입
현재가 $130 / 1년 고점 $200 / 보유 없음
분할 계획: 1차 300만 · 2차 300만 · 3차 400만

[수익] 종목 B · 평단 대비 +15%
현재가 $115 / 평단 $100 / 보유 20주

[손실] 종목 C · 평단 대비 -20%
현재가 $80 / 평단 $100 / 보유 10주
```

**규칙**

- 구간을 벗어났다가 다시 들어오면 재알림. 단, 같은 종목·같은 구간은 하루 최대 1번
- **경계선 여유 2%p:** 구간 기준보다 2%p 이상 회복해야 "구간을 벗어났다"고 본다 (예: -35% 구간은 -33%까지 회복해야 이탈). 경계선에서 오르락내리락할 때 같은 알림이 반복되는 것을 막는다
- 한 번에 여러 구간을 내려가면 가장 깊은 구간 1개만 알린다
- 추가 매수로 평단이 바뀌면 수익·손실 구간을 새 평단 기준으로 다시 계산
- 알림은 즉시 보내지 않고 밤사이 모아 오전 9시 아침 브리핑(6장)에 담아 1번만 발송

## 5. 앱 화면 구성

폰 홈 화면에 아이콘으로 설치해 쓰는 앱이며, 하단 탭 4개로 구성한다. 열자마자 Top 10 시세판이 보이게 해서 영웅문을 열지 않아도 확인할 수 있게 한다.

| 탭 | 화면에 보이는 것 |
| --- | --- |
| Top 10 (첫 화면) | 실시간 시세판. 종목마다 현재가·전일 대비, **1년 고점(보라색으로 강조)**, **1년 고점 대비 %(큰 글자)**. 맨 위에 매수권장·매수검토 종목 수. 하락률순·시총순 정렬. 앱을 보고 있는 동안 1분마다 자동 갱신 |
| ETF | 규모 상위 10개 ETF를 Top 10과 같은 형식으로 따로 표시 |
| 브리핑 | 오늘의 아침 브리핑, 지난 브리핑을 날짜별로 다시 보기 |
| 알림 | 받은 알림 이력 (매수권장·매수검토·수익·손실). 누르면 해당 종목 상세로 이동 |

**표시 원칙:** 매수권장은 빨간 테두리 상자, 매수검토는 주황 테두리 상자로 눈에 띄게 구분한다. 그 외 종목은 기본 색. 막대그래프·"다음 알림" 같은 부가 표시는 넣지 않고 숫자를 글자로 바로 보여준다.

**종목 상세 화면:** 1년 가격 선 하나에 1년 고점(보라)·매수검토 시작선(-5%, 주황)·매수권장 시작선(-20%, 빨강)을 가로선으로 표시하고, 구간별 가격표와 그 종목의 알림 기록을 보여준다. 2단계에서 내 평단 선과 3분할 계획 금액을 추가한다. 차트 지표는 넣지 않는다.

**3분할 계산기 (종목 상세 안):** 그 종목에 넣을 총 투자금만 입력하면 30/30/40으로 나눠 금액과 현재가 기준 대략적인 주수를 보여준다. 키움 잔고와 대조해 몇 차까지 샀는지, 남은 금액이 얼마인지도 함께 표시하고, 매수권장·매수검토 알림에도 다음 분할 금액이 같이 나간다.

| 예: 총 1,000만 원 | 금액 | 주수 (현재가 $140, 환율 1,400원 가정) |
| --- | --- | --- |
| 1차 (30%) | 300만 원 | 약 15주 |
| 2차 (30%) | 300만 원 | 2차 시점 가격으로 다시 계산 |
| 3차 (40%) | 400만 원 | 3차 시점 가격으로 다시 계산 |

**설정 (첫 화면 우측 상단):** 알림 구간·간격, ETF 목록, 알림 받을 시간대, 증권사 연결 상태.

## 6. 아침 브리핑 (매일 오전 9시)

실시간 푸시는 보내지 않는다. 밤사이 생긴 알림과 Top 10 이슈를 **매일 오전 9시 한 번에 묶어 신문처럼** 보내고, 사장님은 아침 루틴으로 한 번만 보면 된다. 미국 장은 한국 시간 새벽 5~6시에 끝나므로 9시면 전날 장이 모두 반영된다.

| 지면 | 내용 |
| --- | --- |
| 1면 내 계좌 | 총 평가금액·수익률과 전날 대비 변화, 밤사이 수익(+5%마다)·손실(-10%마다) 구간에 들어간 보유 종목 |
| 2면 매수권장·매수검토 | 매수권장(-20% 이상), 매수검토(-5~-15%) 종목·ETF를 하락률 큰 순서로. 새로 구간에 들어온 종목은 NEW 표시, 다음 분할 금액 함께 |
| 3면 Top 10 이슈 | 종목별 전일 등락률, 1년 고점 대비 위치, 주요 이슈 1~3줄과 원문 링크 |
| 4면 일정 | 이번 주 실적 발표 등 예정된 일정 |

**작성 원칙**

- 사실만 쓴다. "매수 기회", "전망이 밝다" 같은 의견·예측 문장은 넣지 않는다
- 이슈가 없는 종목은 "특이사항 없음" 한 줄로 끝낸다
- 3면 이슈는 알림 판단에 쓰지 않는다. 1·2면은 끝까지 가격과 평단만 본다
- 일·월요일 아침은 전날 미국 장이 없어서 계좌 현황과 이번 주 일정만 담는다

```text
[10/27 화 아침 브리핑]

■ 1면 내 계좌
총 수익률 +12.4% (전일 대비 -0.8%p)
- 종목 B: 평단 대비 +15% 구간 진입

■ 2면 매수권장·매수검토
- [매수권장] 종목 A: 1년 고점 대비 -35% (NEW) · 1차 300만 원
- [매수권장] ETF C: 1년 고점 대비 -21%
- [매수검토] 종목 F: 1년 고점 대비 -8%

■ 3면 Top 10 이슈
종목 A  전일 -4.2% · 1년 고점 대비 -35%
- 분기 실적 발표: 매출 증가, 다음 분기 가이던스 하향
종목 D  전일 +0.8% · 특이사항 없음

■ 4면 일정
- 종목 E 실적 발표 (10/29)
```

## 7. 기술 구성

평단과 시세는 사장님이 쓰는 **키움증권(영웅문 Global) 계좌를 키움 REST API로 조회**해 가져오고, 앱은 안드로이드 폰 홈 화면에 설치하는 **웹앱(PWA)** 으로 만든다. 키움 REST API는 미국주식 계좌·차트·순위 조회를 지원한다 ([지원 범위 정리](https://algolab.co.kr/blog/kiwoom-us-overseas-stock-api-support-2026)).

| 구성 요소 | 선택 | 비고 |
| --- | --- | --- |
| 평단·보유 수량 | 키움 REST API 미국주식 계좌 조회 | 조회 권한만 사용. 정확한 TR은 개발 시 키움 공식 명세서에서 확인 |
| 시세·1년 고점 | 키움 미국주식 일 차트 조회 | 최근 1년 일별 데이터로 고점 직접 계산 |
| 환율 | 키움 환율 조회 | 3분할 계산기의 주수 계산용 |
| 종목 시총 Top 10 | 키움 순위정보 또는 공개 시가총액 데이터 | 매월 1회 갱신, 변동 시 앱 공지로 안내 |
| ETF Top 10 | 공개 ETF 순자산 순위 데이터 | 키움 API의 ETF 카테고리는 국내 전용이라 순위는 외부 데이터 사용, 시세는 키움으로 조회 |
| 앱 | 웹앱(PWA) | 안드로이드 크롬에서 홈 화면에 추가 → 앱처럼 전체 화면 실행 |
| 푸시 알림 | 웹 푸시 | 안드로이드는 별도 설정 없이 바로 수신 |
| 공지 자료 | 뉴스 API + 미국 공시(SEC) | 종목별 전날 뉴스·공시를 모아 원문 링크와 함께 저장 |
| 공지 요약 | Claude API | "사실만, 의견 금지" 규칙으로 종목별 1~3줄 요약 |
| 서버 | 소형 클라우드 서버 | 미국 장은 한국 시간 밤~새벽이라 상시 실행 필요 |
| 로그인 | 사장님 전용 계정 1개 | 앱 접속 시 비밀번호·지문 인증 |

**확인 주기:** 알림 판단은 장중 10~30분 간격이면 충분하다. 5% 단위 구간을 잡는 방식이라 초 단위 속도는 필요 없고, 키움 API 호출 한도에도 여유가 생긴다. 시세판은 앱을 보고 있는 동안에만 1분마다 새 시세를 받아온다.

**사전 준비:** 키움 홈페이지에서 REST API 이용 신청과 앱키 발급을 하고, 해외주식 사용 동의가 별도로 필요한지 함께 확인한다.

## 8. 단계별 개발 로드맵

앱 기본 화면과 가장 쓸모가 큰 Top 10 시세판·하락 알림부터 만들고, 각 관문을 통과하면 다음 기능을 더한다.

| 단계 | 내용 | 다음 단계로 넘어가는 조건 |
| --- | --- | --- |
| 1단계 앱·Top 10 | 앱 기본 화면, Top 10 실시간 시세판, 하락 알림(매수검토·매수권장) | 알림 구간이 내 감과 일치 |
| 2단계 보유 알림 | 키움 조회 연동, 수익 +5%·손실 -10%, 3분할 계산기 | 평단·수익률이 증권사 앱과 일치 |
| 3단계 아침 브리핑 | 뉴스·공시 수집, AI 사실 요약, 매일 9시 발송 | 브리핑에 의견 문장 없음 |
| 4단계 ETF·기록 | ETF Top 10 탭, 알림 이력 정리, 설정 화면 완성 | - |

1단계만으로도 "차트를 안 봐도 관심 구간을 놓치지 않는다."는 핵심 효과가 나온다. 2단계는 증권사 API 신청이 필요해 1단계 개발 중에 미리 신청해 둔다.

## 9. 안전장치

주문 기능이 없으니 돈이 잘못 나갈 위험은 없다. 남은 위험은 **알림·공지가 틀리거나, 안 오거나, 남에게 보이는 것**이라 그 세 가지를 막는다.

| 장치 | 내용 |
| --- | --- |
| 주문 기능 없음 | 주문 코드를 아예 만들지 않음. 증권사 API는 조회 권한만 사용 |
| 이상값 필터 | 하루 -50% 같은 비정상 데이터는 알림 대신 "데이터 확인 필요"로 표시 |
| 알림 폭주 방지 | 같은 종목·같은 구간 하루 1번, 급락장에서는 종목별 알림을 묶어서 1개로 발송 |
| 생존 확인 | 아침 브리핑이 안 오면 시스템이 멈춘 것 → 바로 알 수 있음 |
| 공지 검증 | 요약마다 원문 링크 필수, 의견·예측 표현이 들어가면 자동으로 걸러냄 |
| 앱 접근 제한 | 사장님 계정만 로그인, 비밀번호·생체 인증 |
| 키 보안 | 증권사·뉴스·Claude API 키는 서버 환경변수로만 보관, 앱 화면 코드에는 넣지 않음 |

## 10. 확정 사항과 남은 확인

핵심 값은 모두 확정됐다. 남은 것은 키움 API 신청 하나다.

| 항목 | 확정 값 |
| --- | --- |
| 증권사 | 키움증권 (영웅문 Global), 키움 REST API 조회 |
| 폰 | 안드로이드 |
| 감시 종목 | 미국 시총 상위 10개 종목 |
| 감시 ETF | 규모(순자산) 상위 10개 ETF |
| 하락 알림 | 1년 고점 대비 -5%부터 5%p마다 끝까지 (종목·ETF 동일) |
| 단계 | 매수검토 -5~-15% (주황), 매수권장 -20%부터 (빨강) |
| 경계선 여유 | 2%p 이상 회복해야 구간 이탈로 봄 |
| 첫 화면 | Top 10 실시간 시세판 (1분 자동 갱신) |
| 보유 종목 알림 | 평단 대비 수익 +5%마다, 손실 -10%마다 |
| 3분할 | 종목별 총 투자금 입력 → 30/30/40 자동 계산 |
| 알림 방식 | 실시간 푸시 없이 매일 오전 9시 아침 브리핑 (계좌·매수권장/검토·Top 10 이슈·일정) |
